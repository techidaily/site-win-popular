## Karaoki Beta Update 0.9.n7579 Now Includes Singer Scroll & PCDJ Improvements - Get It Today!

[![Karaoki singer scroll](https://i1.wp.com/pcdj.com/wp-content/uploads/2020/10/singers.png?resize=752%2C321&ssl=1)](https://i1.wp.com/pcdj.com/wp-content/uploads/2020/10/singers.png?fit=752%2C476&ssl=1 "Karaoki singer scroll")

A new Karaoki beta version is ready for download! Now with various new news ticker and screen 2 options, including singer scroll.

Karaoki beta version 0.9.7579 can be downloaded and installed below. You’ve been asking for it and patiently (for the most part, anyway 🙂) waiting and it’s ready for testing — the upgraded news ticker feature now includes the ability to display your upcoming singers on the scroll.

Not only does version 0.9.7579 include the singer scroll option, but you can now creating/use multiple ticker messages, multiple screen 2 background images, change the color of the text based on the background image you’re using, and more. Yes, the Karaoki dev team has been busy in the bat cave!

Please download/install Karaoki version 0.9.7579 below with your existing version of Karaoki closed to update now. If you have feedback feel free to post in the comments section below or on the [PCDJ Facebook User Group](https://www.facebook.com/groups/208451843303338/).

### New and Changed In Karaoki Beta 0.9.7579

* **Addition** – New dedicated page for “Screen 2” Backgrounds and ticker
* **Addition** – Support for multiple “Screen 2” backgrounds and ticker messages
* **Addition** – Ticker text color, ribbon color and singers list (On screen 2) can now be set with the background image
* **Addition** – Singer output list can now be disabled.
* **Addition** – Singers can now be displayed on the ticker.
* **Change** – Ticker message dialogue and background selection removed from config page.
* **Change** – displayed singers settings moved from “Rotation Options” to “Ticker/ Background” page.
