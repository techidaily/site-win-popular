### The official public release of DEX 3.16 is ready for download!

[View Larger Image ![DEX 3 KSR Online Songbook](https://i1.wp.com/pcdj.com/wp-content/uploads/2021/04/krs-request-system.png?fit=300%2C240&ssl=1 "DEX 3 KSR Online Songbook")](https://i1.wp.com/pcdj.com/wp-content/uploads/2021/04/krs-request-system.png?fit=1030%2C823&ssl=1)

DEX 3.16 is here and as always, it’s a free update for DEX 3 DJs. Learn more below and download and install the update from the [DEX 3 support page](https://tools.techidaily.com/pcdj/products/).

DEX 3.16 brings new karaoke-specific features and extensive optimizations and bug fixes for both the latest macOS’s (Catalina and Big Sur) and Windows 10\. The two most notable feature additions that should have KJ’s crooning are the built-in [KSR (Karaoke Singer Request)](https://tools.techidaily.com/pcdj/products/) system that allows you to host your karaoke songbook online so your singers can view, search, and make requests from their own mobile device that are sent to the DEX 3 karaoke rotation list, and the new Karaoke Singer Scroll/News Ticker.

After extensive public testing on the [PCDJ User Group](http://www.facebook.com/groups/pcdjusergroup/), DEX 3.16 is ready for live performance. We suggest DEX 3 customers update to 3.16 today!

### What’s New, Changed, and Fixed in DEX 3.16

* [KSR (Karaoke Singer Request) System](https://tools.techidaily.com/pcdj/products/): A seamless integration in DEX 3, the new KSR system allows you to host your karaoke songbook online so singers can view, search, and make requests – as well as add to their own “favorites” folder and view the rotation queue. [Learn more about KSR and how to configure the system in DEX 3](https://tools.techidaily.com/pcdj/products/)
* Karaoke singers ticker/scroller (scrolled list of singers + custom message) with text color setting. Not only will this scroll your upcoming karaoke sings across the bottom of the screen, but you can add a custom message at the end (eg. display the [ksr.pcdj.com](https://tools.techidaily.com/pcdj/products/) web address for the new KSR request app, special drink offer, etc.) Example: Now Appearing: Ryan (Songname), Upcoming: Jane (Songname1), Joe (Songname2), Chris (Songname3) \*\* Tequila Shots $4 Until 9pm \*\* (This feature needs to be enabled under the karaoke settings tab in DEX 3’s options).
* Fixed issue with obscure karaoke zip files and video files causing crash on load to deck
* Extensive optimizations, Performance improvements, and fixes (especially for macOS Big Sur)
