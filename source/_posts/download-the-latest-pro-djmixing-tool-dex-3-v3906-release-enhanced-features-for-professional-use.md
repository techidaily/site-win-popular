That’s something to sing about if you’re a DJ/KJ hosting karaoke with DEX 3 with the HD karaoke online/offline streaming service. As always, the DEX 3.9.0.6 update will install directly over-top your existing [DEX 3](https://tools.techidaily.com/pcdj/products/) version, keeping all your lists, data and settings intact.
